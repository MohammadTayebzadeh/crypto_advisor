# 🧠 Crypto Advisor – Streamlined Macroeconomic News Analyzer for Crypto Traders

**Crypto Advisor** is a Streamlit-based AI-powered assistant that helps crypto traders stay up to date with macroeconomic and coin-specific news. Instead of getting lost in countless headlines, Crypto Advisor delivers curated insights using Google Gemini API and web scraping from trusted sources—saving time and improving clarity in trading decisions.

---

## 🎯 Purpose

The goal of Crypto Advisor is to:
- Assist in analyzing **macroeconomic news** and **coin-specific updates**
- Provide **summarized, relevant insights** using AI
- Offer a **customizable assistant experience** based on your prompt style

## ⚙️ Tech Stack

- **Language**: Python
- **Web Scraping**: BeautifulSoup
- **Frontend/UI**: Streamlit
- **AI Integration**: Google Gemini API
- **Other Tools**: Requests, re, etc.

---

## 🚀 Key Features

- ✅ Scrapes trusted crypto and macroeconomic news sources
- ✅ Uses **Google Gemini API** for summarizing and interpreting news
- ✅ Customize your assistant by changing the **prompt** logic
- ✅ Clean, minimal Streamlit UI for ease of use
- ✅ Ongoing improvements and optimization

---

## 🧠 AI Customization

You can personalize the assistant behavior by **changing the prompt sent to Gemini API**.  
This allows:
- Different styles of summarization
- Filtering by sentiment, keywords, or region
- Designing a news assistant tailored to your strategy
